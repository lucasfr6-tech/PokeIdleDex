# Gardevoir Chic

Sprites supplied by the owner (Gardevoir Tana 2013, normal and shiny), cropped from the owner's selection board and reduced to their native pixel size with a transparent background:

- `gardevoir-chic.png` (normal)
- `gardevoir-chic-shiny.png` (shiny)

In-game exclusive species: 90006, Casino Diamond ticket only.

`gardevoir-chic-3d.webp` and `gardevoir-chic-shiny-3d.webp` are smooth 3D-shaded animated versions (36 frames, 60 ms) generated from those sprites: Scale2x ×8 smoothing, relief lighting (normals from a height map, diffuse, specular and rim light), floating, breathing and dress flutter. The matching `.png` files are their first frames.

# Lugia Ombre et Mewtwo Black

Sprites supplied by the owner in `pokeIdleDex Game.zip`, copied unchanged. Original archive paths:

- `poke/sshadow/lugias.png` → `lugia-ombre.png`, `poke/sshadow/lugia.png` → `lugia-ombre-shiny.png`
